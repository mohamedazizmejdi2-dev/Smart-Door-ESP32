# ESP32 Smart Door Security System

## Overview

This project implements an IoT-based smart door security system using an ESP32 microcontroller. It combines embedded programming, access control, and remote monitoring.

## Hardware Components

* ESP32 development board
* Servo motor (MG90S)
* 20x4 LCD with I2C interface
* Buzzer
* Ultrasonic sensor

## Software and Technologies

* Arduino IDE
* C/C++
* ESP32
* Blynk IoT platform

## Features

* Door control using a servo motor
* LCD-based status display
* Audible alerts using a buzzer
* IoT monitoring through Blynk

## Project Files

* `src/`: Arduino source code
* `report/`: Project documentation
* `wiring/`: Wiring notes and diagrams, if available

## How to Run

1. Install the Arduino IDE.
2. Install the required ESP32 and project libraries.
3. Configure your Wi-Fi and Blynk credentials.
4. Connect the components according to your wiring diagram.
5. Upload the code to the ESP32.
